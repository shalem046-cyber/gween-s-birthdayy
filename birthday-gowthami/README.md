# Gowthami's Birthday Surprise

A responsive birthday page for 12 October 2026.

## Add the photos

Place three image files in this folder's `images/` directory with these exact names:
- `gowthami-1.jpg`
- `gowthami-2.jpg`
- `gowthami-3.jpg`

The page uses those files in the gallery. Prefer three photos that are okay for the recipient to see on a public web link. GitHub Pages websites and assets are publicly accessible when hosted from a public repository.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save. If Pages is already enabled on this repository, allow the deployment to finish.
