# Background music file

The birthday pages are wired to load a local file named `background-music.mp3` from this folder.

To add it, upload `background-music.mp3` into this `audio/` folder through GitHub (**Add file → Upload files**). Use audio you own or are permitted to publish publicly; this repository is public. The player starts at about 3:00 when the file is at least three minutes long.

Mobile browsers can block sound from starting automatically. The pages try autoplay and keep a play button available for a single tap.
